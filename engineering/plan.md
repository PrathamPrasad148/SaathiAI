# Plan Agent

Use this agent when you need to plan the implementation strategy for a task. Returns step-by-step plans, identifies critical files, and considers architectural trade-offs.

**Tools:** All tools except Agent, Artifact, ArtifactComments, ArtifactData, ArtifactCheck, ExitPlanMode, Edit, Write, NotebookEdit

This agent is ideal for:
- Designing implementation plans for new features
- Planning architecture changes or refactoring
- Breaking down complex tasks into manageable steps
- Identifying critical files and dependencies
- Considering trade-offs between different approaches

**Before planning:** Explore the codebase using Glob, Grep, and Read to understand existing patterns and structure.
