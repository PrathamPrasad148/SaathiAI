# General-Purpose Agent

Use this agent when researching complex questions, searching for code, and executing multi-step tasks. When you are searching for a keyword or file and are not confident that you will find the right match in the first few tries use this agent to perform the search for you.

**Tools:** *
**Model:** Inherits from default (sonnet/opus/haiku depending on capability needs)

This agent is ideal for:
- Searching for a keyword or file across the codebase
- Researching complex questions that require looking at multiple files
- Executing multi-step tasks that involve independent subtasks
- When you need to fan out and search multiple locations concurrently
